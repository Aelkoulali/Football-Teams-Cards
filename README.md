# 🗂️ Building Football Teams Cards ⚽
This project builds football team player cards using HTML, CSS, and JavaScript. It displays team information, renders player cards dynamically from an array of objects, and lets the user filter teammates using a dropdown with switch statements and array methods.

## ✅ Key Features
- Displays team stats: team name, sport, year, and head coach
- Renders player cards dynamically from a players array
- Filter teammates using a dropdown:
  - All players
  - Nicknames only
  - Forward / Midfielder / Defender / Goalkeeper
- Updates the UI instantly on dropdown change (DOM manipulation + event handling)
- Uses object destructuring to simplify reading data
- Protects the team object using `Object.freeze()`

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## JavaScript Concepts Used
- DOM manipulation
- Object destructuring
- Event handling (`change` event)
- Data filtering (`filter()`)
- Switch statements
- Default parameters
- `Object.freeze()`
- `map()` for generating card HTML
